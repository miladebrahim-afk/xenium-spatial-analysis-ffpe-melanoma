# Metadata

This directory contains public templates describing metadata required for analyses that use treatment-response information.

The template file:

`patient_treatment_response_annotation.template.csv`

contains column headers only and does not contain patient-identifiable information or study-specific clinical data.

Actual treatment-response metadata used for manuscript analyses are private and must not be committed to this repository.

For local reproduction of response-related analyses, place the private metadata file in:

`private_provenance/patient_treatment_response_annotation.xlsx`

The private provenance file is excluded from GitHub.
